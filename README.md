# 🌍 Time Zone Dropdown

A simple, lightweight world clock web app that displays the current local time for selected cities around the world.

## 📸 Preview

Select a city from the dropdown and instantly see the current date and time for that timezone in a browser alert.

## ✨ Features

- Dropdown menu to select from multiple cities
- Displays the current local time and date for the selected city
- Built with vanilla HTML, CSS, and JavaScript — no frameworks needed

## 🛠️ Built With

- **HTML5**
- **JavaScript**
- **[Moment.js](https://momentjs.com/)** — date/time formatting
- **[Moment Timezone](https://momentjs.com/timezone/)** — timezone conversion
